What I do

Six things I've done repeatedly, in production, on software other people depend on.

  • Operators & controllers

    Custom operators and controllers, CRD and API design, single- and multi-cluster architecture. Including the unglamorous half: reconcile loops that behave, statuses that tell the truth, and tests that catch the bug before your users do.

  • API gateway & traffic policy

    Gateway API and policy-engine-style systems — rate limiting, authentication, DNS-based routing. I've led a gateway feature from architecture RFC through to a coordinated set of merged PRs across several repositories.

  • Cloud-native DNS & networking

    DNS automation for Kubernetes: health checking, endpoint generation, geo-routing, and multi-provider setups. I owned a DNS operator's health-check subsystem end to end, and the CLI that operators use to debug it.

  • Auth & secrets integration

    Moving workloads off static, long-lived credentials and onto Vault-based, short-lived auth. I've made this call mid-feature and reworked three open PRs to do it properly rather than ship the easy thing.

  • AI-assisted developer tooling

    Agentic workflows that survive contact with a real team: a Claude Code plugin adopted team-wide, automated documentation verification, and AI wired into review and CI in ways that help rather than generate noise.

  • Technical writing & onboarding

    Setup guides, observability docs, troubleshooting, and the contributor processes that turn a repository into a project. Good docs are cheaper than good support, and I enjoy writing them.
